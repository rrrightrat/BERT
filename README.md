# BERT
A Minecraft Bedrock Edition Redstone Toolkit that consists of  simple tools that help make the overall designing and building process better by letting it calculate long calculations for you.

# to run in terminal

Copy and paste the commands in your terminal

1. Install OpenJDK (use latest ver. replace 21 with latest ver.), git and gradle:

```bash
pkg install openjdk-21 git gradle -y
```

2. Clone this repository:
```bash
git clone https://github.com/rrrightrat/BERT.git
```
3. Open Athelgard directory:
```bash
cd BERT
```
4. Build/compile the code:
```bash
gradle build
```
5. Run:
```bash
gradle run
```
OR use this if gradle doesn't work:
```bash
java -cp build/classes/java/main com.bert.Main
```
